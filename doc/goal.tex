\chapter{Modelling Choices}
The considerations presented in chapter \ref{ch:why} translate in the following modelling choices

\begin{itemize}
    \item The model must be Stock Flow Consistent.
    \item The model should represent an economy with explicit capital goods, firms and workers to allow for different future matching strategies and endogenous innovation.
    \item The model should have a stylized financial side to allow for profit income to be distributed and to observe the effects of the endogeneity of money.
    \item The behaviour of the government should include pro-cyclical and anti-cyclical policies.
    \item Taxation should model different kind of taxes to be able to modulate the fiscal policy with different redistributive effects.
\end{itemize}

Some additional choices have been made:
\begin{itemize}
    \item A Leontief production function is used to take advantage of the matching mechanism in the agent-based extension between an integer number of workers and an integer number of capital goods.
    \item Government consumption is endogenous with a target deficit mechanism inspired by EU's rules.
    \item Most behavioural equation are inspired by post-Keynesian theory \parencite{lavoie2022}.
\end{itemize}

The model has been developed incrementally and each iteration will be presented in its SFC version(s) and subsequently in the AB extension.
The step-by-step approach, while it can be common in the development, is rarely documented. This should be the first AB-SFC model to document a step-by-step construction.
