\chapter{Introduction}
Starting from the discussion made in chapter \ref{ch:why} the goal of the model and the required features are now listed.

\begin{itemize}
\item The model must be Stock Flow Consistent.
    \item The model should represent an economy with explicit capital goods, firms and workers to allow for different future matching strategies and endogenous innvoation.
\item The model should have a stylized financial side to allow for profit income to be distributed and to observe the effects of the endogeneity of money.
\item The behaviour of the goverment should include pro-cyclical and anti-cyclical policies.
\item Taxation sould model different kind of taxes to be able to modulate the fiscal policy with different redistributive effects.
\end{itemize}

Some additional choices has been made:
\begin{itemize}
    \item Having explicit workers and capital goods the choice of a Leontieff production function appears obvious.
    \item Government consumption is endogenous with a target deficit mechanism as in EU.
    \item Most behavioural equation are inspired by post-keynesian theory \parencite{lavoie2022}.
\end{itemize}

The model has been developed incrementally and each iteration will be presented in its SFC version(s) and subsequently in the AB extension.
