\chapter{An Introduction to the Models}
In the following chapters the versions of the model will be presented.
The model has been built up progressively, with new elements introduced in each version.
For each version four variants will be presented (where relevant): an SFC variant with endogenous government spending; an SFC variant with exogenous government spending; two AB-SFC variant (one matrix-based in R and one OOP-based in Python) with endogenous government spending, written as close as possible to the aggregate one.

Bold letters will indicate assets, calligraphic ones sectors.
Where not otherwise specified, the variables refer to current period, while a ${t-1}$ subscript is used to denote a lagged variable.

All the R code written for the simulations is available online\footnote{\url{https://github.com/TnTo/BAS}}% and in the appendix \ref{app:code}
.
